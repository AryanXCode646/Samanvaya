⚡ Quickstart: Local Setup & Alignment

Run in terminal to launch the interactive portal or execute headless registration.

# 1. Clone & Setup Repository
git clone https://github.com/ashishsinghbora/Samanvaya.git
cd Samanvaya
./start.sh   # For Windows PowerShell: .\start.ps1

# 2. Launch Interactive Streamlit Dashboard
streamlit run app.py --server.port 8501

# 3. Headless CLI Alignment & USGS ISIS3 GCP Export
python -m lunar_core.cli align --reference lunar_core/assets/sample_data/scenario_a_ohrc.tif --secondary lunar_core/assets/sample_data/scenario_a_lro_nac.tif

# 4. Execute Full Verification Test Suite (62 Tests)
pytest tests/ -v --maxfail=1
